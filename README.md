## 🧪 Practice

The `Practice/` folder contains hands-on questions and scenarios based on the topics covered in the course.

> [!IMPORTANT]
> Practice files contain **questions and tasks only**. They do not contain answers or solutions.

The workflow is:

```text
Practice Question
       ↓
Attempt the Solution
       ↓
Review / Feedback
       ↓
Improve Understanding
```
